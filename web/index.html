Shortform Audio Bookshelf

Sign in to reach your library.

The server cannot write to its config folder, so accounts will not persist. Fix the folder's permissions, then restart the container.

First run? Sign in with admin / admin, then change the password.

Settings

Nothing can be saved. Accounts, resume positions and the index will be lost on restart. In Docker this is normally the config folder's owner not matching PUID/PGID.

No login is set — anyone who can reach this server on your network can listen, upload files and change these settings.

The default password is still in use. Anyone who can reach this server can sign in as admin / admin. Change it below.

Folders

Library folder
Scanned for audiobooks. Uploads are saved straight into it.
Organised output folder
A tidy copy is written here when you organise. Must be outside the library.

Setting the folder only records where. Organise makes the copy: Author/Title/01 - Chapter.opus with a playlist, cover and book.json per book. Your originals are never moved or changed.

Book details

Look up descriptions, narrators and covers for every book that has none, from Audible and Apple Books, plus an author bio from Wikipedia or Open Library for each new author it meets. Roughly a second per book, so a large library takes a while — it runs in the background and you can stop it. Only confident matches are applied; anything doubtful is skipped.

Network

Saving moves the server to the new address straight away — no restart. If the port is already in use, nothing changes and you stay where you are.

Accounts

    Listeners can browse and play, and keep their own place in each book. Admins can also scan, add, remove and look up details.
    Stored as PBKDF2 hashes. Passwords still cross your network in the clear, so treat this as a lock for home use, not the internet.

    Find book details

    Your files carry only title, author and genre, so descriptions and narrators come from Audible, Apple Books or Google Books. Nothing is applied until you pick one, and your audio files are never modified.
